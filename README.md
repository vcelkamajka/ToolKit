List of varied python programmes - used for menial / broad day-to-day work. In the repository, .csv files are supplied which are used in the examples set out in each programme.

**Colour Tools:** Used for getting the most common colour(s) from an image - useful for art or ensuring consistency. Also features a tool to make a colour spectrum starting from an rgb value.

⭐ **RDKitting:** Used for getting molecule diagrams, 3D views, descriptors, similarities and database searches.

⭐ **Chemistry Models:** Used for matching data from a) drug release mechanisms, b) surface isotherms and c), the Arrhenius equation. This helps find the best model to describe your data and gives the parameters it fit. 

**Calibration Curve:** Used for reading .csv files with columns: 0 = run I.D or number, 1 = x values and, 2 = y values. This returns the standard deviation of the sample, alongside the mean for each run also. Running .get_curve() produces a plot with (linear) line of best fit alongside the actual data with error bars.

**Buffer Calculator:** Used to find the correct molar ratios of [A-] and [HA] with pKa to get the correct buffer pH. Can also calculate pH based on the Henderson-Hasselbalch equation.

⭐ **Titration Curve:** Used to read a .csv file of volume and pH - this allows the user then to smooth the curve via a Savitzky-Golay filter or with a spline. This then generates a first and second derivative which finds the equivalent point(s). If pKa values are known, an ideal species plot can also be made.

**MiniPy:** Used to perform various statistical tests (t-test, anova, post-hoc...). Can also generate distribution plots, box-plots, normality tests, etc.,

⭐ **PhD File Sorter:** Used to a) rename any files using metadata (if PDF) and also, b) redirect downloads to a different folder for sorting.
